# 실제 상품 데이터 공급처 검토 (2026-11-14)

## 확인된 제약
- NAVER Developers 공식 공지(2026-06-29): 기존 쇼핑 검색 API는 2026-07-31 종료되었고 NAVER API HUB로 이관되지 않았으며 대체 API도 제공되지 않음. https://developers.naver.com/notice/article/32530
- NAVER API HUB에 일반 검색 관련 API가 있더라도, 상품 가격/판매처/리뷰 데이터가 반환되는 쇼핑 검색 API가 있다고 가정하지 말 것.
- 쿠팡·컬리·11번가 등 각 판매처의 상품 데이터를 임의 스크래핑하거나 공개되지 않은 엔드포인트를 사용하는 것은 기본 연동 방식으로 채택하지 않음. 공급자의 공식 제휴/승인과 재사용 조건 확인 필요.

## 데이터 확보 전략
1. 공식 제휴 API 또는 데이터 공급 계약을 확보한 판매처부터 연결
2. 제조사 공식몰·공장직영몰의 직접 제공 상품 목록(CSV/JSON)을 수집하는 자발적 등록 채널 마련
3. 이용자가 직접 확인한 상품 정보의 수동 등록/일괄 등록은 계속 지원
4. 가격/용량/배송비/원산지/성분 등 항목의 근거 URL, 수집 시점, 공급자 표기를 향후 필수화
5. 품질 평가 근거가 없는 경우 순위 점수는 확정하지 않음. 브랜드 인지도/판매량은 가산점 없음.

## 구현 상태
- Android 앱은 JSON products 배열을 반환하는 사용자 설정 HTTPS API에 연결 가능
- Node 서버는 환경변수 FOOD_UPSTREAM_URL로 허가된 공급 API에 연결 가능
- 실제 API 계약, 서버 배포, API 자격증명 및 매핑 작업은 아직 완료되지 않음
