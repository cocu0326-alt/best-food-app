🛒 쇼핑몰에서 상품 찾기

쇼핑몰 검색은 외부 페이지로 이동합니다. 제조사 직영·생산자 직거래 제품도 직접 등록해 동일 기준으로 비교할 수 있습니다. 가격과 평점은 확인 후 아래에 직접 등록하세요. 연동 서버가 설정되어 있으면 포함 검색어 추가 시 상품을 자동 조회합니다. 서버 미설정 상태에서는 직접 등록할 수 있습니다.

📋 여러 제품 한 번에 등록

쇼핑몰에서 확인한 제품 정보를 탭으로 구분하여 붙여넣으세요. 한 줄에 상품명, 가격(원), 용량, 단위(g/mL), 평점, 리뷰 수, 판매처 순서입니다. 첫 줄 제목은 생략하거나 포함할 수 있습니다.

직접 확인한 실제 상품 정보만 입력하세요. 품질·제조정보는 등록 후 확인 전 상태로 처리됩니다.

🔌 상품 검색 API 연동 (시험 기능)

상품 데이터를 제공하는 HTTPS API 주소가 있다면 검색어를 전달해 결과를 불러옵니다. API는 JSON 형식의 products 배열을 반환해야 합니다. 조회된 상품명·가격·평점·원산지·원재료는 공급업체 제공 정보로, 앱이 독립 검증한 결과가 아닙니다. 품질 평가와 제조정보 확인 여부는 자동 부여하지 않습니다. 인증키가 필요한 API는 키를 앱에 직접 입력하지 말고 서버 중계 방식을 사용해야 합니다.

연동 서버 미설정 · 자동 검색 비활성

무료 공개데이터 또는 무료 제공 API만 연결하세요. 유료 API·유료 서버 사용은 필요하지 않습니다. 가격 출처와 조사일을 확인한 후 비교하세요.

서버 없이 무료 가격조사 CSV 파일을 직접 열어 검색할 수도 있습니다. 한국소비자원 공식 CSV 다운로드 후 아래에서 파일을 선택하세요. 조사 가격은 실시간 판매가가 아닙니다.

💾 비교 데이터 백업·복원

등록한 상품과 검색 조건을 JSON 파일로 보관하고 다른 기기로 옮길 수 있습니다. 복원 시 현재 데이터는 교체됩니다.

🏆 종합 TOP 10

검색어 포함·제외 조건을 상품명에 적용합니다. g와 mL는 서로 다른 단위로 가격 점수를 계산합니다. 단위별 상품이 1개라면 가격 점수는 중립적으로 처리됩니다. 등록한 제품만 비교합니다. 평가 기준: 품질 35%, 가격 30%, 구매자 평가 25%, 제조정보 10%. 품질 근거가 없는 제품은 점수를 확정하지 않고 '평가 보류'로 표시하며 종합 추천순에서 순위를 부여하지 않습니다. 단위가격 정렬은 g와 mL를 각각 묶어 정렬합니다. 품질 점수는 입력자 판단이며 검증된 인증 점수가 아닙니다. 각 제품의 '평가 수정'에서 품질 근거와 제조정보 확인 여부를 보완할 수 있습니다. 판매량과 브랜드 인지도는 점수에 반영하지 않습니다.
