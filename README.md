# 최고의 식품 (Android)

식품 상품 정보를 직접 등록하거나 HTTPS API에서 가져와 가격·용량·평점·리뷰·품질 근거를 비교하는 Android WebView 앱입니다.

## APK 만들기

1. GitHub 저장소에서 **Actions → Android APK build → Run workflow**를 실행합니다. `main` 브랜치에 푸시해도 자동 실행됩니다.
2. 실행 결과가 녹색 체크 표시인지 확인합니다. 실패했다면 실패한 단계의 로그를 확인합니다.
3. 해당 실행 화면 아래 **Artifacts → best-food-debug-apk**를 다운로드합니다.
4. ZIP 파일을 압축 해제한 뒤 `app-debug.apk`를 Android 기기에 옮겨 설치합니다. 기기에서 해당 파일 설치 허용을 요구할 수 있습니다.

**중요:** APK 생성과 실제 설치 성공은 별개입니다. 현재 이 문서는 빌드 성공을 보증하지 않습니다. GitHub Actions가 실행되지 않는다면 저장소 Settings → Actions에서 실행 허용 여부를 확인해야 합니다.

## 주요 기능

- 상품 직접 등록 및 탭 구분 텍스트 대량 등록
- 가격·용량·평점·리뷰 등 기준의 상품 비교 및 TOP 10
- JSON 백업 및 복원, 상품 CSV·가격 변동 CSV 내보내기
- HTTPS 서버 API 설정 및 상품 조회

## 데이터와 제약

- 상품 및 검색 조건은 기기 WebView의 로컬 저장소에 보관됩니다. 앱 데이터 삭제나 재설치 전에 JSON 백업을 권장합니다.
- 실제 쇼핑몰 가격·재고·평가 데이터는 자동으로 제공되지 않습니다. 별도 API 서버와 데이터 공급원이 필요합니다.
- API는 HTTPS를 사용해야 하며 브라우저 접근 시 CORS 설정이 필요할 수 있습니다.
- 앱 내 백업/CSV 내보내기는 Android 파일 저장창을 사용합니다. 브라우저로 직접 열 때는 일반 다운로드 방식입니다.
- 외부 쇼핑몰 링크는 Android 기본 브라우저로 열립니다.

## 자동 검증

`.github/workflows/android-apk-build.yml`에서 앱에 포함된 JavaScript 문법 검사, 공공 가격조사 CSV 회귀 테스트, Android APK 빌드 및 패키지 이름 확인을 순서대로 수행합니다. 검사가 실패하면 APK 빌드 단계로 진행하지 않습니다. 실제 단말 실행과 파일 입출력은 별도 확인이 필요합니다. CSV 단독 테스트는 `.github/workflows/consumer-price-csv-tests.yml`에서도 실행됩니다.

## 무료 데이터로 사용하기

1. 앱의 검색어 입력창에 상품명을 입력합니다.
2. [한국소비자원 참가격 공공데이터](https://www.data.go.kr/data/15083256/fileData.do)에서 CSV를 내려받습니다.
3. 앱의 CSV 파일 선택 버튼으로 내려받은 파일을 엽니다. 검색어가 있으면 자동 검색하며, 검색어 변경 시에도 결과가 갱신됩니다.
4. 동일한 상품명과 조사일의 표시된 결과끼리 최저가·최고가·차액을 확인합니다. **이는 과거 조사 가격이며 현재 온라인 결제 가격이 아닙니다.**

실시간 상품 가격을 자동으로 가져오려면 이용 권한이 있는 공급 API와 HTTPS 서버가 필요합니다. 앱에는 유료 API 가입이나 유료 서버를 강제하지 않으며, 인증키를 앱에 직접 넣지 않습니다. 서버 구성은 [`server/README.md`](server/README.md)를 참고하세요.
